# Mahnaz Aliyar – personal website

A small, dependency-free static site (plain HTML and CSS) served by GitHub Pages.

| Page | File |
| --- | --- |
| Home | `index.html` |
| CV | `cv/index.html` |
| Research | `research/index.html` |
| Interests | `interests/index.html` |

Shared styles live in `assets/style.css`; images are in `assets/img/`.

To add a new tab (for example *Free resources* or *Media*), copy one of the existing page folders, edit the content, and add one `<a>` line to the `<nav>` in every page.

## Address

The site is served at <https://mahnazaliyar.com>. The `CNAME` file in the repository root tells GitHub Pages which domain to use, so please leave it in place.
